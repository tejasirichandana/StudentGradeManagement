# Student Grade Management System
A Java-based application developed during my CodeOrbit Tech Internship. This project allows users to manage student grades dynamically by entering the number of students, subjects, subject names, and marks.

# Features
- Dynamic student count
- Dynamic subject count
- Dynamic subject names
- Average calculation
- Grade generation
- Highest average student
- Lowest average student
- Class average calculation
- Marks validation
- Exception handling

# Technologies Used
- Java
- Arrays
- Loops
- Scanner Class
- Exception Handling
